# Source Data for Scalable Wide-Bandgap Perovskite Mini-Modules

This repository contains the machine-readable source data associated with the manuscript:

**“Controlled Film Formation Enables Scalable Wide-Bandgap Perovskite Modules for Tandem Applications”**

The study investigates coating-speed-dependent film formation in blade-coated wide-bandgap (WBG) perovskites and its relationship with spatial photoluminescence (PL) uniformity, photovoltaic performance, and device upscaling from small-area cells to perovskite mini-modules.

## Source Data

All numerical source data are provided in:

**`Source_Data.xlsx`**

The Excel workbook contains the data underlying the main and supplementary figures, including:

- J–V characteristics and photovoltaic parameters
- Coating-speed-dependent device statistics
- External quantum efficiency (EQE) spectra
- Film-thickness measurements
- X-ray diffraction (XRD) data
- Hyperspectral photoluminescence (PL) data and spatial analyses
- Mini-module photovoltaic performance and statistics
- Maximum-power-point (MPPT) measurements
- Four-terminal perovskite/silicon tandem measurements

Individual worksheets are labeled according to the corresponding figures or datasets in the manuscript and Supporting Information.

## Data Format

The data are provided in Microsoft Excel (`.xlsx`) format. Each worksheet contains machine-readable numerical values together with the relevant variable names and units.

Where applicable, sample identifiers, coating conditions, device areas, and measurement conditions are included to facilitate interpretation and reproduction of the reported analyses.
